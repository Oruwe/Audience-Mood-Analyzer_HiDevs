# Runtime

# Every entry below is imported by code that runs in production. Four
# packages were removed once they turned out not to be: `instructor` and
# `langfuse` (CONVENTIONS.md names both, but no module imports either and no
# LLM callback is wired -- listing langfuse under an "Observability" heading
# advertised tracing this project does not actually do), `pytz` (nothing
# imports it; the stdlib `zoneinfo` is what ingestion/youtube.py uses). `scipy`
# went too -- scikit-learn pulls it in regardless, so pinning it here only
# implied a direct dependency that does not exist.
#
# `python-dotenv` was very nearly removed alongside them and then earned its
# place: nothing imported it, but that was the bug, not the justification.
# This repo ships a .env.example, gitignores .env, and the README tells you to
# copy one to the other -- and no code ever loaded the result, so the
# documented local setup reported all three keys missing.
